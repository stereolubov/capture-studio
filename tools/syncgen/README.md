# syncgen — замер A/V-синхронизации записи

Эталонный генератор для проверки требования ТЗ к синхронизации звука и видео.
Окно 480×270 мигает белым, и в тот же момент звучит щелчок 1 кГц. Оба события привязаны
к одним часам QPC: кадр показывается в выбранную развёртку монитора (фактическое время
показа берётся из статистики swapchain), щелчок ставится сэмпл-в-сэмпл по часам аудиоустройства.
Генератор пишет журнал событий, анализатор сравнивает с ним запись и выдаёт ошибку
самой записи без учёта погрешности источника.

## Сборка

```
cargo build --release -p syncgen -p cs-app
```

Нужны Python с numpy и ffmpeg/ffprobe (в `PATH` или в переменной `FFMPEG_DIR`).

## Замер

Ручной режим: сами запускаете запись в Capture Studio, окно генератора должно быть в кадре.

```
powershell -File tools\syncgen\scripts\measure.ps1 -RecDir "<папка записей>"
```

Автоматический режим: отдельная папка данных, скрипт сам нажимает кнопку записи.
`-ClickX/-ClickY` — координаты кнопки в логических пикселях окна; значения по умолчанию
подходят для 4K при масштабе 150%.

```
powershell -File tools\syncgen\scripts\measure.ps1 -Auto -DataDir <папка> -RecDir <папка>\rec -Runs 3
```

Отдельно:

- `syncgen --seconds 30 --x 200 --y 200 --out events.json` — только генератор;
- `python scripts/analyze.py <запись> events.json` — анализ записи по журналу;
- `python scripts/analyze_clip.py <запись>` — анализ без журнала (вспышки против щелчков в
  любом ролике, например из плеера).

## Как читать результат

`ошибка записи (звук − видео)`: плюс значит, что звук в записи позже картинки.

- Отдельные события разбросаны на ±8 мс. Это дискретность кадров при 60 fps, она есть у любой записи.
- У каждого запуска генератора своя погрешность в несколько миллисекунд, поэтому записи
  сравнивайте внутри одного запуска (так делает `-Auto`).
- Замер на 2026-10-28 (RTX 5080, Sound BlasterX G6, 60 Гц): средняя ошибка от +1 до +17 мс,
  повторяемость записей ±3 мс.
