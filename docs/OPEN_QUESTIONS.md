# Открытые вопросы и расхождения с ТЗ

Вопросы §20 ТЗ действуют со значениями «по умолчанию», пока заказчик не ответит. Ниже —
вопросы, найденные при реализации.

| # | Вопрос | Решение до ответа | Обратимо |
|---|---|---|---|
| Q1 | §20 п.1 — лицензия проекта | **Решено 2026-10-28: MIT** (ADR-0007). GPL-зависимости (x264 и др.) исключены, LGPL — только динамически через ADR | — |
| Q2 | Ширины 1e (560 px) и 1f (340 px) в ТЗ взяты из `width` макета, но макет использует content-box: с отступами и рамкой окна фактически **602** и **370 px** | Сделано как в отрисованном макете (ТЗ §11 требует совпадения со скриншотом макета); содержимое 560/340 px | да |
| Q3 | Индикатор уровня: в макете градиент считается от ширины *заливки* (при любом уровне конец полосы жёлто-красный), ТЗ §8.2 задаёт зоны по *шкале* (−20 / −9 dBFS) | По ТЗ: зоны привязаны к шкале, плавные переходы на 70% и 85% | да |
| Q4 | §20 п.6 — вторая полоса в микшере сплошная `ok` в макете | По умолчанию ТЗ: L/R; обе полосы с зонами | да |
| Q5 | Плавающие 1c/1d/1e внутри главного окна, а не отдельные окна ОС | ADR-0006; у 1d/1e добавлен «✕» в правом верхнем углу (в макете его нет) | да |
| Q6 | 1e: ниже графика добавлена строка «Подробнее ▸ / Копировать отчёт» (требование §11.5, в макете нет) — высота окна 341 px вместо 304 | Оставлено (требование ТЗ важнее) | да |
| Q7 | 1c: «Расширенные ▸» размещены слева в строке кнопок, чтобы не менять высоту окна макета | Оставлено | да |
| Q8 | Оценка «~2.7 ГБ/час»: по формуле §9.3 получается 2.77 | Округление вниз до 0.1 (оценка не завышается), совпадает с макетом | да |
