# Открытые вопросы и решения

Ответы заказчика фиксируются здесь и в ADR. Пока ответа нет, действует значение «по умолчанию» из ТЗ §20.

## Решено (2026-10-28)

| # | Вопрос | Решение |
|---|---|---|
| §20.1 | Лицензия проекта | **MIT** (ADR-0007). GPL исключён, LGPL — только динамически через ADR |
| §20.2 | Другие ОС | Только Windows; платформенный код изолирован за трейтами (по умолчанию) |
| §20.3 | Браузерный источник в v1.0 | **Да**, в v1.0 — отдельным скачиваемым модулем (§7.4); выбор CEF/WebView2 — ADR перед реализацией |
| §20.4 | Сертификат подписи кода | Нет, **нужно получить**. План — `docs/signing.md` (рекомендация: SignPath Foundation для open source) |
| §20.5 | UI-фреймворк | egui (ADR-0002) |
| §20.6 | Полосы микшера 1d; значение дБ | **L/R**, обе с цветовыми зонами; дБ над каналом — **положение фейдера** |
| §20.7 | Сервисы трансляции | Приоритет и тесты на реальном сервере — **Twitch, YouTube**. Остальные (VK Видео Live, Rutube, Kick, Trovo) — в списке выбора, параметры проверяются перед публикацией (`assets/services.toml`) |
| §20.10 | Распространение | Публичный репозиторий GitHub `stereolubov/capture-studio`, релизы — GitHub Releases. Автообновление из GitHub Releases — запланировано (ADR-0008, черновик) |
| Q3 | Зоны индикатора: макет (от ширины заливки) или ТЗ (от шкалы) | **Как в ТЗ** §8.2: зелёная до −20, жёлтая −20…−9, красная −9…0 dBFS |
| Q2 | Ширины 1e/1f: 560/340 (ТЗ) или 602/370 (отрисованный макет) | **Пока как в макете** (602/370); пересмотреть, если визуально будет лучше иначе |
| Q5 | 1d/1e внутри главного окна или отдельными окнами | **Не закреплять принудительно**: панели можно открепить в отдельное окно ОС (например, на второй монитор). Реализация — M3 (ADR-0006, дополнение) |
