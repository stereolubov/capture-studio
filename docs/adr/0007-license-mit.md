# ADR-0007: Лицензия проекта — MIT

**Контекст.** §20 п.1. Ответ заказчика (2026-10-28): открытый некоммерческий проект для свободного
использования, предпочтительно MIT.

**Решение.** Весь код — MIT (`LICENSE`, `license = "MIT"` во всех крейтах).

**Последствия для зависимостей.**
- Разрешены: MIT, Apache-2.0, BSD, ISC, Zlib, Unicode, OFL (шрифты), MPL-2.0 (пофайловый copyleft).
- **Запрещены GPL/AGPL** в любом виде, включая x264 и GPL-сборки FFmpeg: MIT-проект не может их
  распространять, не став GPL. Программный H.264 — OpenH264 (BSD, §9.1).
- **LGPL — только динамически**, отдельной DLL в опциональном модуле (например, `libavformat` для
  ремукса, §10.1) и только через отдельный ADR.
- OpenH264: при загрузке официального бинарника Cisco патентные отчисления за H.264 покрывает Cisco;
  при сборке из исходников — нет. План для M2: скачивать бинарник Cisco по требованию.
- Аппаратные SDK (NVENC, AMF, oneVPL) — заголовки MIT/BSD, загрузка драйверных DLL в рантайме.

`deny.toml` уже разрешает только перечисленные пермиссивные лицензии.
