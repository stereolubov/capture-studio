# ADR-0005: Ротация логов по размеру без tracing-appender

**Контекст.** §12.1: логи — 10 файлов × 10 МБ; §14.2 упоминает `tracing-appender`, который умеет только
ротацию по времени.

**Решение.** Собственный `RotatingWriter` (~80 строк, `cs-diag/src/log.rs`) как `MakeWriter` для
`tracing-subscriber`: новый файл при каждом запуске и при достижении 10 МБ, хранится 10 файлов.
Запись синхронная под мьютексом — объём логов мал (info по умолчанию).

**Альтернативы.** `tracing-appender` + ротация по дням — нарушает §12.1; `file-rotate` — лишняя зависимость.

**Последствия.** Если в M2+ логирование станет частым в горячих путях — обернуть в `non_blocking`
(собственная очередь), горячие пути пишут только атомарные счётчики (§14.1).
