# ADR-0006: Настройки, микшер, статистика — панели внутри главного окна; мини-режим — то же окно

**Контекст.** §11.3 — модальное окно настроек; §11.4 — микшер «отдельное окно или док-панель — через ADR»;
§11.5 — окно статистики; §11.6 — мини-режим поверх всех окон.

**Решение.**
- 1c — модальная панель поверх затемнённого главного окна (Esc/«Отмена» закрывают).
- 1d, 1e — плавающие перетаскиваемые панели (egui `Area`) внутри главного окна; Esc закрывает, добавлен «✕».
- 1f — то же HWND переводится в компактный режим: `HWND_TOPMOST`, без `WS_THICKFRAME`, размер 370×104,
  `SetWindowDisplayAffinity(WDA_EXCLUDEFROMCAPTURE)` на Win10 2004+; положение главного окна сохраняется
  и восстанавливается, позиция мини-окна запоминается в `settings.toml`.

**Альтернативы.** Отдельные HWND с собственными swapchain — больше кода и памяти (каждый swapchain
и DComp-цель), сложнее синхронизация состояния; выигрыш только при нескольких мониторах.

**Последствия.** Нельзя вынести микшер на второй монитор — при запросе пользователей добавить отдельные
окна (egui viewports поверх того же устройства) в v1.x.
