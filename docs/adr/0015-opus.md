# ADR-0015: Opus — libopus из исходников (`opus-head-sys`), только в MKV

Статус: принято (2026-10-30).

## Контекст

ТЗ §9.2: AAC-LC через Media Foundation (обязателен для RTMP) и Opus (libopus, BSD) — для
MKV/WebM и будущих WHIP/SRT. Нужен эталонный кодер (libopus), статическая сборка без
DLL рядом с exe.

## Решение

- Крейт `opus-head-sys` (привязки MIT/Apache-2.0, исходники libopus BSD-3 в комплекте),
  без default-фич (без DNN-моделей DRED/OSCE). libopus собирается из исходников и линкуется
  статически; **для сборки нужен CMake** (есть в Visual Studio Build Tools и на GitHub Actions
  `windows-latest`; в PATH или через переменную `CMAKE`).
- Кодер (`cs-encode/src/opus.rs`): 48 кГц стерео, `OPUS_APPLICATION_AUDIO`, переменный битрейт из
  настроек (32–510 кбит/с), сложность 10, кадры по 20 мс (блоки микшера по 10 мс копятся).
  Метка пакета — время первого отсчёта кадра на входе; разрыв меток больше 10 мс (пауза)
  начинает кадр заново.
- MKV: `A_OPUS`, CodecPrivate — `OpusHead` (RFC 7845), `CodecDelay` = задержка кодера (312
  отсчётов, 6.5 мс), `SeekPreRoll` = 80 мс.
- Только формат «MKV»: в форматах с MP4 (ремукс, MP4, fMP4) пишется AAC — Opus в MP4 плохо
  понимают монтажные программы. В настройках: «Расширенные → Аудиокодек», при формате с MP4 —
  предупреждение. fMP4-мультиплексор отвергает не-AAC дорожки.

## Альтернативы

- `audiopus_sys`: libopus 1.3 (2019), сборка тоже через CMake.
- Чистые Rust-реализации (`rusty-opus`, `opus-rs`): не эталонный кодер, зрелость не проверена.
- Своя сборка libopus через `cc` без CMake: ~200 C-файлов и их список в репозитории — дороже
  сопровождать.
- Opus в MP4 (`Opus` + `dOps`, `elst` под pre-skip): возможно позже, если понадобится.

## Последствия

- Проверено: модульные тесты (кадры по 20 мс, `OpusHead`, перезапуск после паузы); запись MKV с
  Opus — ffprobe: `opus` 48 кГц стерео, ffmpeg декодирует без ошибок, A/V по `syncgen` −12 мс
  (медиана, 20 событий).
- Найдено: на том же прогоне AAC в MKV даёт +16 мс. Разница ~28 мс — задержка кодера AAC
  (1024 отсчёта, 21 мс), которая в файле не объявлена, плюс задержка Opus. То есть AAC
  «маскирует» сдвиг таймлайна около −10 мс. Обе цифры в пределах ±20 мс (§17), но задержку AAC
  и общий сдвиг нужно разобрать на приёмке M2 (2.13).
- Сборка требует CMake — отмечено в README.
