# ADR-0003: Доступ к D3D11-устройству из нескольких потоков (черновик, решение в M1)

**Контекст.** §5.2 п.3: рендер-поток компоновщика отделён от UI-потока, но устройство единое (§5.2 п.1).
Immediate-контекст D3D11 не потокобезопасен.

**Решение M0.** Устройство используется только UI-потоком. В M1 планируется: компоновщик владеет
immediate-контекстом в рендер-потоке; UI получает готовую текстуру превью через keyed mutex / shared
handle (`ID3D11Texture2D` с `D3D11_RESOURCE_MISC_SHARED_KEYEDMUTEX` на том же устройстве) и рисует
egui через отдельный deferred-контекст или через `ID3D10Multithread::SetMultithreadProtected(TRUE)`.
Выбор — по замерам времени кадра UI и компоновщика в M1.

**Последствия.** API `GpuDevice` в M1 изменится (обёртка над контекстом с синхронизацией).
