# Подпись кода

**Зачем (§16.1).** Без подписи Windows SmartScreen показывает «неизвестный издатель», антивирусы чаще
дают ложные срабатывания на хук и инжектор (`cs-hook.dll`, `cs-inject-*.exe`), часть античитов
отказывается загружать неподписанные модули.

Сертификат нельзя «сгенерировать» самим: доверие даёт удостоверяющий центр после проверки личности
или организации. Самоподписанный сертификат годится только для локальных тестов.

## Варианты

| Вариант | Стоимость | Подходит нам | Комментарий |
|---|---|---|---|
| **SignPath Foundation** (open source) | бесплатно | **да — рекомендация** | Требования: OSI-лицензия (MIT ✓), публичный репозиторий ✓, сборка в CI (GitHub Actions ✓). Подписывается артефакт CI, ключ хранится у SignPath. Подписантом значится SignPath Foundation |
| Certum «Open Source Code Signing» | ~€25–70/год + смарт-карта/облако | да | Сертификат на имя разработчика-физлица; подпись локально или из CI через облачный ключ |
| Azure Trusted Signing | ~$10/мес | ограниченно | Для физлиц доступен не во всех странах; нужна верификация |
| OV/EV от коммерческого УЦ | $200–600/год | избыточно | Для некоммерческого проекта дорого |

## План

1. Подать заявку в SignPath Foundation после публикации кода и первого релиза из CI
   (у них требуется действующий проект с историей).
2. До одобрения — неподписанные сборки; в CI шаг подписи подключается переменной окружения
   (`xtask dist --sign`, этап M5).
3. Для локальной разработки при необходимости — самоподписанный сертификат
   (`New-SelfSignedCertificate -Type CodeSigningCert`), только на машине разработчика.
4. Обновления (ADR-0008) дополнительно подписываются собственным ключом ed25519 — независимо от
   Authenticode, чтобы проверка не зависела от УЦ.
