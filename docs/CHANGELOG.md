## [Unreleased]

### Added — M2 «Аудио и запись» (частично)
- Аудиодвижок WASAPI (loopback, микрофон), микшер 48 кГц с дорожками 1–6, индикаторы, MMCSS.
- Запись: аппаратный H.264 (Media Foundation), AAC, собственный MKV-мультиплексор, ремукс в MP4,
  пауза, проверка места на диске, асинхронный старт (без пропуска кадров).
- Смещение синхронизации канала −950…+2000 мс (§8.2): «Настройки → Аудио» и меню шестерёнки микшера.
- `tools/syncgen` — эталонный генератор вспышка+щелчок для замера A/V-синхронизации записи.
- Фильтры канала (§8.3): цепочка до фейдера, окно «Фильтры» из шестерёнки канала (добавить,
  включить, переставить, удалить), сохранение в профиле. Первый фильтр — усиление −30…+30 дБ
  с плавным изменением. Цепочка собирается вне аудиопотока, микшер подменяет её с переносом
  состояния — без выделений памяти и щелчков.
- Фильтр «Шумоподавление (RNNoise)» (крейт `nnnoiseless`, BSD-3): по сети на канал, моно-сигнал
  считается один раз. Задержка фильтра (480 кадров, 10 мс, проверяется тестом) вычитается при
  выравнивании канала — синхронизация не уходит. Модель встроена в exe (+1.2 МБ).
- Фильтр «Шумовой гейт»: пороги открытия/закрытия с гистерезисом, атака, удержание, спад
  (по умолчанию −26/−32 дБ, 25/200/150 мс). Огибающая — пик по обоим каналам со спадом 10 мс.
- Фильтр «Компрессор»: порог, степень сжатия, атака, спад, компенсация усиления (по умолчанию
  −18 дБ, 4:1, 6/60 мс, 0 дБ). Детектор — пик по обоим каналам, сглаженный атакой и спадом.
- Фильтр «Лимитер»: потолок и спад (по умолчанию −1 дБ, 60 мс), мгновенная атака без задержки —
  выход не превышает потолок. Список фильтров в окне прокручивается, если не помещается.

### Changed — синхронизация звука (§5.2 п.4, §8.1)
- Очередь канала хранит метки времени захвата по пакетам; каналы выравниваются по общей шкале
  микшера с фиксированной задержкой (40 мс, растёт, если источнику не хватает), метка блока —
  время захвата его звука. Убрана оценка задержки со сглаживанием (обратная связь давала
  разброс ±10 мс между записями) и двойная поправка на задержку вывода loopback.
- Фаза сетки меток видеокадров — по первому кадру записи.

### Added — M1 «Компоновщик, превью, базовые источники»
- Рендер-поток с высокоточным таймером, компоновщик D3D11 (обрезка, поворот 90°, переход «Затухание»),
  замер времени компоновки на GPU.
- Превью сцены без копий (текстура холста в egui).
- Источники: захват экрана (WGC / DXGI Desktop Duplication), захват окна (WGC, автоприкрепление),
  изображение (PNG/JPEG/WebP), цвет, текст (DirectWrite, обводка).
- Редактирование сцен: добавление и свойства источников, перетаскивание порядка, видимость, блокировка,
  трансформации мышью с привязкой, контекстное меню, Undo/Redo, переходы, автосохранение коллекции.
- Глобальные горячие клавиши сцен (`RegisterHotKey`).

### Fixed
- Запись: сетка меток видеокадров считается по точной частоте (дробью). С целой длительностью
  кадра (166 666 × 100 нс) сетка за час уходила от тиков рендера почти на кадр, и в середине
  часовой записи шли пачки пропущенных кадров (0.9 %, счётчик пропусков их не видел).
- Запись: метка кадра — плановое время тика рендера минус задержка захвата, которая переносится
  в метку ступенькой, только когда ушла больше чем на полкадра. Живая задержка ползёт в пределах
  кадра (таймер рендера и развёртка монитора идут с чуть разной частотой) и дрожит: прямо в метке
  она давала одиночные пропуски (до 1.4 % кадров, не видные в счётчике), а замороженная на старте
  за час уводила синхронизацию на кадр (до +38 мс).
- Статус-строка: у счётчиков фиксированная ширина, соседние значения не сдвигаются при смене разрядности.
- `cargo deny`: из сборки убраны неиспользуемые шрифты egui (лицензия Ubuntu Font); exe 5.8 → 5.2 МБ.
- Индикаторы уровня при дробном масштабе (125–175%): часть заливки была на 1 px выше дорожки.

### Added — M0 «Каркас и UI-оболочка»
- Cargo workspace из 12 крейтов по §5.3; toolchain 1.99.1, edition 2024.
- `cs-core`: модель сцен, снимок состояния, команды/события, мастер-часы QPC, мок-движок.
- Конфиги TOML со `schema_version`, миграциями, атомарной записью (`ReplaceFileW` + `.bak`),
  восстановлением из `.bak` и портативным режимом.
- Логи с ротацией 10 × 10 МБ, маскирование ключей трансляции.
- D3D11-устройство (аппаратное → WARP), собственный рендерер egui, swapchain через DirectComposition.
- Окно без системной рамки: собственный заголовок, Snap Layouts Windows 11, Per-Monitor V2 DPI,
  сохранение положения, единственный экземпляр, приоритет процесса.
- Экраны 1a–1f на мок-данных: главное окно (тёмная/светлая/системная тема), настройки (6 вкладок),
  микшер (перетаскивание, колесо ±1 дБ, двойной клик → 0 дБ, Ctrl+клик → ввод), статистика
  (KPI, график с подсказками, копирование отчёта), мини-режим (поверх окон, исключён из захвата,
  остановка двойным кликом/удержанием).
- Локализация RU/EN (Fluent), тосты, меню заголовка.
- Скриншот-режим `--screenshot` и тесты: сравнение с макетом и эталонами (2 темы × 100%/150%).
- Протокол хука v1 (раскладка shared memory с compile-time проверками для x86/x64).
- CI GitHub Actions: fmt, clippy `-D warnings`, тесты, `cargo deny`, сборка хука x86/x64, бюджет размера exe.
