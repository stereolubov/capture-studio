# Отчёт M1 — Компоновщик, превью, базовые источники

**Дата:** 2026-10-28 · **Статус:** критерии приёмки выполнены (см. ограничения ниже)

## Что сделано

- **Компоновщик** (`cs-gpu/src/compositor.rs`): холст RGBA8, элементы с обрезкой (UV) и поворотом на 90°,
  premultiplied-смешивание, переход «Затухание» через промежуточные текстуры, замер времени на GPU
  timestamp-запросами без ожидания.
- **Рендер-поток** (`cs-app/src/engine`): высокоточный таймер, приоритет HIGHEST, команды из очереди,
  снимок состояния, автосохранение коллекции через 1 с, прогрев источников до начала отсчёта темпа.
- **Превью без копий**: текстура холста регистрируется в egui как нативная (тот же D3D11-устройство).
- **Источники** (`cs-capture`): захват экрана (WGC; DXGI Desktop Duplication — автоматически, если WGC
  недоступен, или по выбору), захват окна (WGC, автоприкрепление по «exe + класс окна», свёрнутое окно —
  последний кадр), изображение PNG/JPEG/WebP (декодирование в отдельном потоке), цвет, текст
  (DirectWrite → текстура, обводка, кириллица).
- **Сцены в UI**: окно добавления и свойств источника; список источников с выделением, перетаскиванием
  порядка, видимостью, блокировкой, контекстным меню; трансформации мышью в превью (перемещение, масштаб
  за углы с Shift, растяжение за стороны, обрезка Alt+сторона, привязка к краям/центру 10 px); стрелки,
  Delete; «Вписать / Растянуть / По центру / Повернуть / Сбросить»; переходы «Срез» и «Затухание 300/500/1000 мс»;
  Undo/Redo (Ctrl+Z / Ctrl+Y, глубина 50).
- **Глобальные горячие клавиши сцен** F1–F9 (`RegisterHotKey`, перенесено из M3 ради приёмки M1),
  предупреждение, если сочетание занято.

## Приёмка (release, RTX 5080, Windows 11, монитор 4K @ 150%)

| Критерий | Результат |
|---|---|
| 1080p60 превью стабильно 60 FPS | **60.0 fps**, **0 пропущенных кадров** за 60 с с ~30 переходами между сценами (захват экрана 4K + цвет + текст + изображение) |
| Время компоновки ≤ 2 мс GPU | **0.02 мс** (timestamp-запросы) |
| Переключение сцен горячими клавишами | F1/F2 глобально, с затуханием — проверено вживую |
| Конфиги переживают перезапуск | Коллекция сцен сохраняется атомарно и восстанавливается (позиции, порядок, активная сцена) |
| CPU / RAM | 0.1% суммарно / 66 МБ рабочий набор при захвате 4K-монитора |

Автотесты: 52 (в т.ч. компоновка и рендер текста на WARP, редактирование сцен и undo, геометрия
трансформаций и привязки, жесты превью, горячие клавиши).

## Найдено и исправлено при проверке

- Кадр UI удерживал блокировку устройства во время `Present` с vsync → компоновщик пропускал кадры при
  переходах (47.8 fps). `Present` вынесен из-под блокировки (ADR-0003).
- Текстуры перехода создавались в момент первого перехода (рывок) → создаются заранее.
- `WM_MOUSELEAVE` во время зажатой кнопки обрывал перетаскивание → игнорируется при захвате мыши.
- Начало жеста отсчитывалось от момента распознавания перетаскивания → от точки нажатия.

## Ограничения и перенос

- Фильтры масштабирования bicubic/Lanczos (§7.3) относятся к масштабированию *вывода* — переносятся в M2
  вместе с конвертером цвета; элементы сцены масштабируются билинейно.
- DXGI Desktop Duplication: курсор пока не рисуется; поворот монитора учтён, но не проверен на повёрнутом
  мониторе. Гибридные ноутбуки — проверка в матрице совместимости (M4).
- Обрезка мышью — только для элементов без поворота (для повёрнутых — через «Сбросить»/свойства в M2).
- Загрузка GPU по процессу (PDH) не реализована — в статус-баре «—».
- Освобождение ресурсов неиспользуемых источников через 5 с (§7.1, опция) — M5.
