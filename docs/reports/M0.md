# Отчёт M0 — Каркас и UI-оболочка

**Дата:** 2026-10-28 · **Статус:** критерии приёмки выполнены

## Что сделано

- Workspace из 12 крейтов по §5.3. Полностью реализованы `cs-core`, `cs-diag`, `cs-gpu` (часть UI),
  `cs-app`; в остальных — интерфейсы и модели для следующих этапов (`VideoSource`, `VideoEncoder`,
  политика переподключения, разбор горячих клавиш, протокол хука v1 с проверкой раскладки x86/x64).
- Окно без рамки на Win32 + D3D11 + DirectComposition, собственный рендерер egui (ADR-0002).
- Экраны 1a–1f на мок-данных из макета; темы тёмная/светлая/системная; RU/EN; DPI Per-Monitor V2.
- Конфиги с миграциями и атомарной записью, логи с ротацией, единственный экземпляр, сохранение
  положения окна и мини-режима.
- Скриншот-режим и автоматические скриншот-тесты; CI.

## Метрики (стенд разработчика: RTX 5080, Windows 11 build 26200, монитор 4K @ 150%)

| Метрика | Бюджет M0 | Факт |
|---|---|---|
| Размер `capture-studio.exe` (release, LTO, strip) | ≤ 10 МБ | **5.2 МБ** |
| Холодный старт до первого кадра | ≤ 800 мс | **459–542 мс** (из них ~330 мс — создание D3D11-устройства драйвером NVIDIA) |
| RAM мок-UI (рабочий набор) | ≤ 60 МБ | **58.5 МБ** (private 66 МБ) |
| CPU в простое с анимацией индикаторов 30 Гц | — | ≈ 1% одного ядра |
| Размер `cs_hook.dll` (x86, заглушка) | ≤ 1 МБ | 8.5 КБ |

Запас по RAM небольшой: основная доля — драйвер D3D11 и swapchain 4K-окна. В M1 проверить
на эталонном стенде §4 (1080p, RTX 3060) и при необходимости уменьшить атлас шрифтов.

## Скриншот-тесты (§17.6)

- `screenshot::tests::main_window_matches_design` — 1a и 1b против эталонов, вырезанных из
  `Capture Studio.dc.html` (headless Edge): отличается < 1.5% пикселей с порогом 40/255 —
  сглаживание шрифтов и зоны индикаторов (Q3). Смещений элементов > 1 px при визуальной сверке нет.
- `screenshot::tests::screens_match_golden` — 5 экранов × 2 темы × 100%/150% против эталонов
  в `crates/cs-app/tests/golden`. Рендер на WARP — детерминирован, работает в CI без GPU.
- Эталоны макета: `tests/design-ref/1a…1f.png`.

## Отклонения от ТЗ и макета

См. `docs/OPEN_QUESTIONS.md`: Q2 (фактические ширины 1e/1f), Q3 (зоны индикатора по шкале),
Q4 (обе полосы микшера с зонами), Q5–Q7 (кнопки «✕», строка «Подробнее», «Расширенные»).
Перенесено: трей и глобальные горячие клавиши — M3; потеря устройства в UI — M5.
