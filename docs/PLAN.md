## Добавлено по решениям заказчика (2026-10-28)
- **M1:** исправлено до начала M1 — индикаторы уровня прижаты к пиксельной сетке (при 150% часть полосы смещалась на 1 px).
- **M3:** открепление микшера и статистики в отдельные окна ОС (ADR-0006, дополнение).
- **M3:** сервисы Twitch и YouTube — приоритет и тесты на реальном сервере; остальные из `assets/services.toml` проверить перед публикацией.
- **M4:** помощник синхронизации (вместе с источником «камера»): хлопок в кадре или страница-генератор
  на телефоне → замер разницы микрофон/видео камеры → предложение значения «Смещения синхронизации»
  (сам ничего не меняет). Разумность и точность оценить на M4. Самопроверка цифрового пути
  (`tools/syncgen`) — как диагностика в окне статистики, не для подстройки.
- **M5:** браузерный источник входит в v1.0 отдельным скачиваемым модулем (ADR: CEF или WebView2).
- **M5:** подпись кода — заявка в SignPath Foundation (`docs/signing.md`); релизы из CI в GitHub Releases с подписанным манифестом.
- **v1.x:** автообновление из GitHub Releases (ADR-0008).
